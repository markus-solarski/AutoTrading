Automated Options Trading Bot (Event-Driven & AI-Assisted)Ein robustes, eigenständig entwickeltes algorithmisches Trading-System, das für den kontinuierlichen 24/7-Betrieb auf einem Raspberry Pi optimiert ist. Der Bot überwacht vordefinierte Basiswerte (Underlyings) und platziert vollautomatisiert Short Put Optionen (Cash-Secured Puts) über die offizielle Interactive Brokers API (IBKR).Das Projekt wurde im Rahmen eines experimentellen Rapid-Prototyping-Ansatzes (Intent-Driven Engineering / Vibe Coding) konzipiert und schrittweise in eine produktionsreife Architektur überführt.
